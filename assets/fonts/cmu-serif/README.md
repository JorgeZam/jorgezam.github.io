# CMU Serif (Computer Modern Unicode)

Web fonts for the running text in the OWCIS style, the typeface LaTeX uses by default.

- Source: npm package `computer-modern` 0.1.3 (https://github.com/stevenpetryk/computer-modern), files `fonts/cmu-serif-{500,700}-{roman,italic}.woff2`
- License: SIL Open Font License 1.1, see `OFL.txt`
- Modified: subset to Latin characters (basic Latin, Latin-1, Latin Extended-A and common punctuation) with fontTools 4.68, to cut each file from about 200 KB to about 40 KB
